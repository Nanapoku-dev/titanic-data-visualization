# Titanic Data Visualization Dashboard

## Overview

This project is an academic coursework project developed as part of **COMP328: Data Science with Python** at Central University, Ghana.

The project explores the Titanic passenger dataset through exploratory data analysis and an interactive dashboard. It presents information about passenger survival, passenger class, gender, age, and fare.

## Features

- Exploratory analysis of the Titanic dataset
- Data cleaning and handling of missing values
- Interactive dashboard for exploring passenger data
- Filtering by passenger class and gender
- Visualization of passenger age distribution
- Visualization of survival statistics
- Visualization of passenger fare distribution
- Summary statistics including total passengers, total survivors, and average age

## Technologies Used

- **Python**
- **Pandas**
- **Plotly**
- **Dash**
- **Jupyter Notebook**
